# Gestión para Proyectos de Grado

Una aplicación web diseñada para la administración, seguimiento y gestión de las sesiones de asesoría en proyectos de grado para los docentes de la **Universidad de San Buenaventura - Sede Cartagena de Indias**.

---

* **Jeremy Alexander Johnson Mena**

---

## Características Principales

* **Gestión de Sesiones:** Registro y seguimiento estructurado de las reuniones de asesoría.
* **Control de Avances:** Monitoreo del progreso académico de los estudiantes en sus proyectos de grado.
* **Interfaz Centralizada:** Herramienta optimizada para coordinadores y docentes asesores de la institución.

---

## Tecnologías Utilizadas

* HTML5
* CSS3
* JavaScript
* Node.js
* Supabase (PostgreSQL)
